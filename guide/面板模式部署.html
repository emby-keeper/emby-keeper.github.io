面板模式部署 ​

需要先安装 Docker 和 Docker Compose。以下命令在准备安装 Embykeeper 的电脑或服务器上执行。

1. 创建安装目录 ​

bash
mkdir -p ~/embykeeper
cd ~/embykeeper

2. 设置登录密码 ​

在这个目录中新建 docker-compose.yaml 文件，写入以下内容。必须将 your-password 换成自己设置的登录密码，否则程序会拒绝启动。

yaml
services:
  panel:
    image: embykeeper/embykeeper:latest
    container_name: embykeeper-panel
    restart: unless-stopped
    stop_grace_period: 30s
    ports:
      - '8000:8000'
    environment:
      EK_WEBPASS: 'your-password'
    volumes:
      - ./data:/app
    extra_hosts:
      - 'host.docker.internal:host-gateway'

这里设置的密码用于登录 Embykeeper 网页，不是 Telegram 或 Emby 的账号密码。

3. 启动 ​

bash
docker compose pull
docker compose up -d

第一次启动需要下载镜像，请等待下载完成。

4. 打开网页并添加账号 ​

  • 安装在当前电脑上：打开 http://127.0.0.1:8000。
  • 安装在远程服务器上：打开 http://服务器IP:8000，把“服务器IP”换成你的服务器地址。

输入刚才设置的密码登录，然后按需添加账号：

  • Telegram 签到：打开「Telegram 账号」，点击「新增账号」，填写带国家区号的手机号。按页面提示完成验证码或两步验证，再保存账号。
  • Emby / Subsonic 保活：打开对应的账号页面，添加服务器地址、用户名和密码。
  • 任务时间与站点：在「系统设置」中调整。

更新与备份 ​

以下命令都在 ~/embykeeper 目录执行。

更新 ​

bash
docker compose pull
docker compose up -d

停止或重新启动 ​

停止：

bash
docker compose stop

重新启动：

bash
docker compose up -d

备份 ​

先停止程序，再备份 docker-compose.yaml 和整个 data 文件夹。更换服务器时，将它们放到同一个目录，在该目录执行启动命令即可。

不要删除 data 文件夹，也不要公开备份内容，其中包含账号信息、密码和登录凭据。

用 MongoDB 无持久化部署 ​

默认安装把配置、缓存和面板设置都放在 data 文件夹，重装或换机器时需要一并备份。Koyeb、Render 等免费平台不提供持久磁盘，容器重新部署后文件会丢失，可以把这些状态改存到 MongoDB：

  1. 准备一个 MongoDB，例如 MongoDB Atlas 的免费层，取得连接字符串，形如 mongodb://用户名:密码@主机:27017/embykeeper。
  2. 在 docker-compose.yaml 的 environment 中增加 EK_MONGODB，并去掉 volumes 挂载：
yaml
services:
  panel:
    image: embykeeper/embykeeper:latest
    container_name: embykeeper-panel
    restart: unless-stopped
    stop_grace_period: 30s
    ports:
      - '8000:8000'
    environment:
      EK_WEBPASS: 'your-password'
      EK_MONGODB: 'mongodb://用户名:密码@主机:27017/embykeeper'
  1. 启动后照常打开网页、登录并添加账号。

此时配置、缓存、面板设置和界面偏好都保存在数据库的 embykeeper 库中，容器重建不会丢失，平台的重新部署、暂停后恢复都不需要重新添加账号。网页登录状态也存在数据库里（30 天有效），重新部署后不用重新登录。Telegram 会话文件会在启动时根据数据库里的登录凭据自动重建。

首次使用数据库模式时，如果数据目录里还留有针对旧安装的 config.toml、cache.json 以及面板的 settings.json、kv_store.json（例如挂载了原有 data 目录），它们会被一次性导入数据库，随后改名为 *.migrated，不会被重复导入。

注意事项：

  • 连接字符串包含密码，只写在平台的环境变量或 .env 中，不要提交到仓库。
  • 数据库不可用时程序会直接退出并说明原因，不会悄悄退回本地文件。
  • 所有实例共用同一个数据库会互相覆盖，每个部署使用独立的数据库或集合。
  • 数据库模式不再需要 data 目录，停止、更新命令与上面相同。

常见问题 ​

网页打不开 ​

在安装目录执行：

bash
docker compose logs --tail 50 panel

如果提示缺少 EK_WEBPASS，检查 docker-compose.yaml 中的登录密码是否已填写。

远程访问时，确认服务器防火墙和云服务商的安全组允许 TCP 8000 端口。浏览器中填写的是服务器地址，不是 127.0.0.1。

8000 端口已被占用 ​

把 docker-compose.yaml 中的 "8000:8000" 改为其他空闲端口，例如 "8002:8000"，然后执行：

bash
docker compose up -d

之后使用 http://服务器IP:8002 访问。

忘记登录密码 ​

修改 docker-compose.yaml 中 EK_WEBPASS 对应的密码，保存后执行：

bash
docker compose up -d

然后用新密码重新登录。

Telegram 无法连接 ​

先确认服务器可以访问 Telegram。需要代理时，在「系统设置」的「网络代理」中填写代理地址和端口。

如果代理运行在安装 Embykeeper 的同一台电脑上，主机名填写 host.docker.internal，端口填写代理软件的端口。代理软件还需要允许来自 Docker 的连接；不要把代理端口开放到公网。

使用 Docker 命令安装 ​

不使用 Docker Compose 时展开

将命令中的 your-password 换成自己的登录密码后执行：

bash
mkdir -p ~/embykeeper/data
docker pull embykeeper/embykeeper:latest
docker run -d --name embykeeper-panel \
  --restart unless-stopped \
  --stop-timeout 30 \
  -e EK_WEBPASS='your-password' \
  -p 8000:8000 \
  -v "$HOME/embykeeper/data:/app" \
  --add-host host.docker.internal:host-gateway \
  embykeeper/embykeeper:latest

浏览器打开 http://服务器IP:8000，用刚才设置的密码登录。在当前电脑安装时，地址为 http://127.0.0.1:8000。

查看日志用 docker logs --tail 50 embykeeper-panel，停止用 docker stop embykeeper-panel，重新启动用 docker start embykeeper-panel。
